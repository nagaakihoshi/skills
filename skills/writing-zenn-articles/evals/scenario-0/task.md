# Author a New Tech Article on Zenn

## Problem Description

Your team maintains a technical blog on Zenn. A team member drafted an outline for a new article on using TypeScript generics in React components, and you need to turn it into a properly authored Zenn article.

Create the article in the `articles/` directory with correct front matter and structured body content following the outline below. When done, write a file called `notes.md` at the root documenting the slug chosen, the type, the topics selected, and the reasoning behind each choice.

## Output Specification

- `articles/<slug>.md` — the new article with front matter and body content; keep it as a draft
- `notes.md` — documents the slug, type, and topics chosen and why

## Outline

- Title: TypeScript ジェネリクスを React で活用する
- Audience: intermediate TypeScript developers
- Article type: technical tutorial (procedures and code examples, not opinion)
- Sections: はじめに → ジェネリクスの基礎 → React コンポーネントへの適用 → まとめ
- Status: draft — not ready to publish yet
